## Перелік лабораторнах робіт
1.	Лінійні програми та базовий ввід-вивід даних 
2.	Арифметичні операції та форматування виводу в Python 
3.	Розгалуження в програмах: умовні оператори та конструкція match-case 
4.	Лінійні операції та базові методи роботи з рядками 
5.	Організація ітераційних процесів (цикли for та while) 
6.	Алгоритмічна обробка текстів із використанням циклів
7.	Побітові операції та низькорівневі маніпуляції з даними
8.	Програмування з використанням функцій: проєктування та виклик
9.	Динамічні списки та одновимірні масиви в Python
10.	Пошукові та сортувальні алгоритми на лінійних структурах даних 
11.	Незмінні колекції: ефективне використання кортежів
12.	Використання асоціативних масивів (словників) для обробки даних 
13.	Операції над множинами та фільтрація унікальних даних
14.	Робота з файлами та обробка винятків (try-except) 
15.	Організація багатофайлових проєктів і створення власних модулів
